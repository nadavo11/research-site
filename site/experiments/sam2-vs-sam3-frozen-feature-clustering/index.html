Interpretation

This still does not mean SAM2 is the better model overall. It does mean that, under same-flavor frozen-feature clustering parity, SAM2 appears more cluster-friendly than SAM3 in most of the published binary partition settings here. The exception matters too: RWTD flip-avg stays a slight SAM3 holdout, so the result is route-specific rather than absolute.

Caveats / Notes

  • Legacy SAM3 coarse-only summaries publish miou/ari instead of eval_miou/eval_ari; this report normalizes those fields directly from the summary bundles.
  • CAID is now included in both same-flavor tables, but the qualitative section remains curated around the clearest RWTD/STLD visual examples.
  • On STLD, miou_agg is visually marked as low-signal because it is nearly constant across both models and both flavors.
  • This is a route-specific frozen-feature clustering comparison, not a claim about overall SAM2-vs-SAM3 project performance.
