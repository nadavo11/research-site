Executive Synopsis

The new Flip Averaged flavor changes the cross-dataset picture materially. It takes the lead on RWTD and STLD, with the largest jump on STLD, while the original Coarse Only flavor still leads CAID.

Cross-flavor comparison is normalized onto the shared ArchiTexture binary evaluator (mIoU, ARI) so RWTD legacy aggregate-only summaries do not distort the page.
